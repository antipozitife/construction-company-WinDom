# WinDom

Адаптивный многостраничный сайт строительной компании — портфолио-проект для демонстрации навыков junior frontend-разработчика.

## Возможности

- каталог домов с фильтрацией и пагинацией;
- страницы жилых проектов с динамическими маршрутами;
- слайдеры построенных домов и команда компании;
- адаптивные desktop/mobile layouts;
- доступные модальные формы с валидацией и управлением с клавиатуры;
- интеграция Яндекс Карт с безопасной конфигурацией ключа;
- отдельная 404-страница.

Формы работают в демонстрационном режиме: данные проходят клиентскую валидацию, но не отправляются и не сохраняются.

## Стек

React 18, TypeScript, React Router, Webpack 5, Swiper, CSS.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm ci
npm start
```

Приложение откроется по адресу `http://localhost:3000`.

## Проверки

```bash
npm run typecheck
npm test
npm run build
```

Все проверки одной командой:

```bash
npm run check
```

## Яндекс Карты

Скопируйте `.env.example` в `.env` и добавьте JavaScript API-ключ:

```env
WINDOM_YANDEX_MAPS_API_KEY=your_key
```

Без ключа сайт показывает текстовый fallback с адресом офиса и продолжает работать без ошибок в консоли.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub и импортируйте его в Vercel.
2. Используйте настройки сборки:
   - Framework Preset: `Other`;
   - Build Command: `npm run build`;
   - Output Directory: `build`.
3. В `Project Settings → Environment Variables` добавьте:

```env
WINDOM_YANDEX_MAPS_API_KEY=your_key
```

Добавьте переменную как минимум для `Production`. Для карты на
preview-деплоях также выберите `Preview`.

4. Запустите новый деплой. После добавления или изменения переменной окружения
   проект необходимо передеплоить.
5. В кабинете разработчика Яндекса ограничьте API-ключ доменом продакшена,
   например `windom.vercel.app`. Укажите домен без `https://`, порта и пути.

Файл `vercel.json` уже содержит настройки сборки и SPA-маршрутизации, поэтому
внутренние страницы сайта открываются напрямую и после обновления.

## Структура

- `src/components` — переиспользуемые UI-компоненты;
- `src/pages` — страницы приложения;
- `src/data` — типизированные данные проектов и домов;
- `src/hooks` — общее поведение, включая доступные модальные окна;
- `img` — оптимизированные изображения и векторные иконки;
- `tests` — быстрые проверки качества проекта;
- `.github/workflows` — CI для typecheck, тестов и production-сборки.
